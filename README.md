# Archery Simulation 🏹

A Python simulation project exploring how shot variability, scoring rules and changing match conditions affect performance in a two-player archery competition.

The project was completed as part of my BSc Financial Mathematics degree at Cardiff University.

## What we explored

- Simulated archery matches using random sampling and probability distributions
- Investigated how changes in shot variability affect accuracy and win rates
- Used repeated simulations to examine long-run performance trends
- Compared standard, French and South Korean scoring systems
- Extended the model to consider factors including weather, fatigue and confidence

## Python

The core simulation uses Python to generate arrow positions, calculate distances from the bullseye and determine round and match winners.

The repository includes the final report and the Python simulation code I retained from the project. Some additional code developed collaboratively for later extensions is not included.
